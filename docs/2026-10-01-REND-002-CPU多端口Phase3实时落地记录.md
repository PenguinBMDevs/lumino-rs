## 一、本阶段交付

### 1. 实时合成管线的端口布局

- `XSynthOptions` 新增 `midi_max_port: u8`（0 = 单端口）；`XSynth` 单独保存当前布局
  字段（`options` 允许为 `None`，且布局只在重建成功后提交，失败保持旧布局）。
- `init_synth` 按 `rt_format(max_port)` 设置 `XSynthRealtimeConfig.format`：
  0 → `Midi`（16 通道，零行为变化）；否则 `Custom{(min(max_port,15)+1)*16}`。
- `Custom` 不自动开 ch9 打击乐（fork 仅 `Midi` 自动，`realtime_synth.rs:698-702`），
  初始化时对每端口 `p*16+9` 显式下发 `SetPercussionMode(true)`（含 port 0）。
- `Api::set_midi_port_layout(max_port)` 默认 no-op；XSynth 实现为“变化才
  `rebuild_with_layout`”，重建成功才提交布局。

### 2. 文档切换与异步初始化对齐

- `MidiManager` 新增 `desired_midi_max_port`：
  - 装载 MIDI/LMPJ/素材：`import_midi_to_editor` 在导入前读取
    `parsed.document.max_port()` 并应用（导入路径开头已 `reset_playback_manager`
    停播），随后创建播放输出连接，保证连接指向正确通道空间；
  - 新建/关闭工程：`close.rs` 应用 0，释放多端口通道空间；
  - 导出自动重载：`export.rs` 幂等对齐。
- XSynth 异步初始化中/System 回退：desired 暂存，`finish_xsynth_init` 成功后
  再 `set_midi_port_layout` 对齐，之后才重连播放输出。

### 3. 播放通道空间与运行时打击乐模态（方案 B）

- `NoteEvent / EventType / MidiMessage.channel` u8 → **u16 全局通道**
  （`port*16+channel`；单端口恒等）。
- 生产侧映射：
  - 当前轨队列（`core.rs`）用 `doc.track_port(current_track)`；
  - 其他轨音符与控制事件（`state.rs`）用 `track_idx` / `ctrl_event.track` 的端口；
  - 当前轨 automation/PC（UI `playback.rs`）按当前轨端口映射；
    `track_midi_events`（HashMap<轨道, _>）按键逐轨映射。
- 共享纯逻辑 `multi_port::PercussionTracker`（midi-model，导出/实时共用）：
  - 默认模态 = `channel % 16 == 9`（每端口 ch9）；
  - GS `CC0=120/121`、XG `CC0=127 && CC32=0` → 打击乐；
    明确非鼓 Bank Select → 旋律；仅 CC32 不单独判定（避免误关默认 ch9）；
  - 切换消息必须**先于**触发 CC 下发（fork 在打击乐模态下忽略 CC0）。
- 实时链路：`state.rs` 在其他轨控制事件与当前轨 automation 中推导模态，
  产生 `MidiMessage::PercussionMode`；`flush` 转为
  `OutputConnection::set_percussion_mode`（默认 no-op，XSynth 发 Channel Config）。
- chase：状态空间按文档 `max_port` 伸缩、删除 `.min(15)`；`PercussionTracker`
  一并追齐，`emit_chase` 先发模态再发 Bank/PC；seek/回绕用追齐快照同步引擎
  内部跟踪器（否则后续 Bank Select 会与旧状态比较而漏切换）。
- 导出链路：`MidiEventProcessor` 用同一 tracker，在 CC0/CC32 触发时先发
  `SetPercussionMode` 再转发 CC（导出/实时同源语义）。
- 暂停清理：新增 `OutputConnection::release_all_dampers`（默认 16 通道 CC64；
  XSynth override 为 `AllChannels`），修复多端口下端口 >0 的踏板持音残留。

### 4. 明确未改动

- 混音台/电平表仍为 16 通道语义（端口 0；`track.channel` 颗粒度）；
- 外部 MIDI 设备仍 4bit 折叠（C1=a）；LGS/GPU 留 #87；
- SysEx（GS/XG Reset、Rhythm Part 重指派）见独立卡 #90（REND-007）。
