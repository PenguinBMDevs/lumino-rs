## 一、改动总览

| 项 | 落点 | 说明 |
|---|---|---|
| **云状态快照化（UI 无锁读）** | `src/runner/cloud.rs`、`cloud_status.rs`、`inner.rs` | 新增 `CloudStatusSnapshot`（无锁 `RwLock`）+ `publish_cloud_snapshot`/`read_cloud_snapshot`；后台 connect/disconnect/delete/auto-connect 完成后发布快照；`ensure_cloud_ready` 与 `refresh_cloud_connections` 等 **UI 读取点全部改读快照**，不再抢跨网络 IO 的业务锁；断开/删除另做乐观更新（不等后台线程） |
| **协作 client 槽位状态机** | `src/services/collaboration_service.rs` | `ClientSlot<C>{Idle/Connecting(token)/Connected}`：每次 connect 递增 token，**只有当前 token 允许提交**；`disconnect` 递增代数使在途连接失效 → 并发 connect 不再互相覆盖、断开后不复活；3 项纯状态机单测 |
| **断连事件接线** | `crates/network/collaboration/src/client/connection.rs` | Close / 流结束 / 传输错误 / 心跳失败 / 发送失败统一 `emit Disconnected`（旧实现只 `state.set`，UI 永远停在"已连接"）；传输错误改为终态退出（旧实现不退出空转）；用户主动断开不发事件 |
| **重连决策（摘除配置）** | `types/client.rs`、`lib.rs` | 删除从未被消费的 `auto_reconnect` / `max_reconnect_attempts` / `RECONNECT_INTERVAL_MS`（"配置承诺 ≠ 行为"信任债），文档明确重连由上层显式发起 |
| **HTTP 超时 + 2× 内存** | `collaboration/src/http.rs` | `Client` 加 connect(10s)/read(30s) 超时（旧 `Client::new()` 无超时）；上传改有界通道逐块流式（峰值 2×→≈1×，旧实现预先把全部块各复制一份） |
| **FTP/SFTP 超时** | `cloud/src/ftp.rs`、`sftp.rs` | FTP 读写超时 30s（`get_ref().set_*_timeout`）；SFTP `inactivity_timeout=120s` + `keepalive_interval=30s`（旧 `SshConfig::default()` 无超时） |
| **幂等读重试** | `cloud/src/manager.rs` | `retry_read`（3 次、200/400ms 退避；未连接/配置/认证等确定性错误不重试）接入 `list_dir`；3 项单测 |
