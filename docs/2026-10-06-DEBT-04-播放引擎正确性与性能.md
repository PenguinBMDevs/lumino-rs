# DEBT-04 播放引擎正确性与性能（#121）

> 来源：全仓屎山扫描 2026-10-06（分片 5）｜优先级 **P1** ｜类型：正确性 / performance

## 背景

GPU 合成与 CPU/离线渲染存在若干**输出正确性**缺陷（Mono/限幅/复位/tempo），
叠加实时与播放路径的**热路径分配**；正确性优先，性能随后。

## 修复方案

1. Mono：实现 mono mix + limiter，或强制 Stereo 并在写出前真降混；CPU/GPU 对拍；
2. limiter `validate()` 要求 `block_size>=256` 或短块零填充延迟头；
3. 抽公共 reset 覆盖全部运行态；连续两次渲染 A/B（无串音）；
4. tempo 稳定排序；流式借用切片；同文档同轨跳过重建；回绕二分起步。
