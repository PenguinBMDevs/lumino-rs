# REF-LGS-009 · 离线导出默认块长 512 → 2048

> 日期：2026-10-31 ｜ 分支：`ref-lgs` ｜ 机器：RTX 5080 / 驱动 610.88 / 48 kHz
> 拍板：**008/009 解耦**——本卡只改离线默认块长，一致性按 008 的分层口径验收。
> 结论：`sustained65536` 墙钟 **2.938 s → 1.180 s（2.5×）**，倍实时 **3.4× → 8.5×**。

---

## 1. 改动

`crates/tools/export/src/audio/gpu_backend/synth_config.rs`：

```rust
pub(super) const GPU_OFFLINE_BLOCK_SIZE: usize = 2048;
// ...
block_size: GPU_OFFLINE_BLOCK_SIZE,   // 原为硬编码 512
```

- **只影响离线导出**（`build_synth_config` 是导出后端专用）；
- 实时路径的块长来自 `LgsOptions::block_size`（`midi-io/src/lib.rs:418` 透传，
  `lgs/init.rs:14` 消费），**本卡未改**；CPU 后端的 `AudioRenderConfig::block_frames`
  也与 GPU 块长解耦（单测覆盖）；
- 合法性由 `SynthConfig::validate` 兜底（2 的幂且 ≥16），非法值在
  `GpuSynth::new` 直接报错，不静默降级；
- 日志新增 `block_size=`，便于导出日志核对实际生效值。

## 2. 性能（`sustained65536`，limiter on，同机同驱动）

| block | 墙钟 | 倍实时 | 相对 512 |
|---:|---:|---:|---:|
| 512（旧默认） | 2.938 s | 3.405× | 1.00× |
| 1024 | 1.815 s | 5.513× | 1.62× |
| **2048（新默认）** | **1.180 s** | **8.499×** | **2.49×** |
| 4096 | 0.921 s | 10.930× | 3.19× |
| 8192 | 0.778 s | 12.945× | 3.78× |

选 2048 不选 4096/8192：2048 已拿到 2.5×，而 4096/8192 每块内存与尾延迟翻倍、
额外收益只有 ~20–30%；2048 也是 A/B 夹具与 008 护栏覆盖最充分的档位。

## 3. 一致性（按 008 分层口径）

`scripts/lgs_block_consistency.py`（渲染层，关 limiter，公共前缀 + 安全带）：

| block | 首个差异帧 | 差异样本 | max\|d\| | RMS | 判定 |
|---:|---:|---:|---:|---:|---|
| 512 | — | 0 | 0 | — | reference |
| 2048 | 12800 | 20925 | 0.336 | −47.9 dBFS | ok |
| 4096 | 12800 | 25657 | 0.336 | −46.6 dBFS | ok |
| 8192 | 12800 | 26701 | 0.336 | −46.6 dBFS | ok |

- 同块长确定性：OK（参考块长跑两遍逐位相同）；
- limiter 在 ≥512 块走绝对帧对齐窗口（REF-LGS-008 A2），不引入块长差异；
- 差异全部落在音符结束的尾段（裁剪块粒度的已知边界，见 008 文档 §6）。

> 卡内"音频与 block 512 逐位一致"按 008 的分层口径执行：**不再要求逐位**，
> 而是 ≤ −45 dBFS 且只出现在尾段。
