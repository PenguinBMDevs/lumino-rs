## 背景

压缩包解压、剪贴板互粘、音频/音色库/缓存文件解析均按"输入可信"编写：
存在路径穿越、预分配 DoS 与越界解析。用户只需打开一个恶意/损坏文件即可中招。

## 证据（file:line）

| 项 | 位置 | 说明 |
|---|---|---|
| **Zip Slip 路径穿越** | `crates/audio/midi-loader/src/archive/extract/backends.rs:75,84,163,168`、`archive/extract/iso.rs:237`、`archive/extract.rs:171` | 条目名直拼输出目录；zip 分支未用 `enclosed_name()`（tar 已用 `unpack`，可对照） |
| 预分配 DoS | `crates/audio/midi-model/src/clipboard.rs:289-295`、`clipboard/domino.rs:99-111` | 19 字节头 count 可达 4.29e9 → `with_capacity` ~68GB |
| WAV 解析 | `crates/audio/gpu-synth/src/audio/wav.rs` | 24-bit 解码公式错（约 256×）、fmt `<16` 越界 panic、data 无界分配 |
| SFZ 越界 | `crates/audio/gpu-synth/src/soundfont/load.rs:168-174` | 后续 packet 声道越界 |
| ISO 回退越界 | `crates/audio/midi-loader/src/archive/extract/iso.rs:156-170` | end 越界 |
| 缓存信任元数据 | `crates/audio/midiplayer/src/texture_waterfall/cache/io.rs:95-132` | `meta_len` 无界 + zstd 无上限 + 未 `validate()` |
| 硬编码 | `load_parsed_midi_from_bytes`（分片 5 M10） | `division:960 / total_notes:0` |

## 修复方案

1. 统一 `sanitize_join`（拒 `..`/绝对路径/盘符 + canonicalize 前缀校验），全部解压入口收口；
2. 预分配与载荷长度夹紧；解压/解压后输出加容量上限；
3. 二进制解析统一 `checked_*` + 边界函数；畸形输入样例库 + fuzz 回归。

## 任务拆解

- [ ] `sanitize_join` + zip/tar/iso 三入口接线 + 恶意样例测试
- [ ] 剪贴板/Domino：count/expected 夹紧 + 解压输出上限
- [ ] WAV/SFZ/MIDI：修公式、补边界、样例回归
- [ ] 瀑布缓存：长度上限 + `validate()` 调用

## 验收

- [ ] 恶意 zip/tar/iso 不写出目标目录、不 panic
- [ ] 超大头 count/压缩比样例内存有上界（不 OOM）
- [ ] 畸形 WAV/SFZ/MIDI 样例不 panic，给用户可见错误
