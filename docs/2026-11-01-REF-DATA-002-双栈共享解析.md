# REF-DATA-002 · 双栈共享 SF2 解析（fork `from_presets` + presets 缓存）

> 日期：2026-11-01 ｜ 分支：`ref-data-002-verify` ｜ 状态：**已实现**
> 结论：同一 SF2 在进程内**只解析一次**；XSynth 与 LGS 共享 `Vec<Sf2Preset>` 里的
> 采样 `Arc`。Jasmine 3.4 GB（debug）LGS 侧从 **29.6 s 重解析** 降为 **8.8 ms 构建**。

---

## 1. 问题（已由验证阶段量化）

同一 SF2 被两套加载栈各解析一次：

- XSynth：`SampleSoundfont::new` 内部调用 `xsynth_soundfonts::sf2::load_soundfont`；
- LGS：`SoundFont::load` 直接调用同一函数；
- 两栈缓存互不共享；Jasmine 上 release 双栈 ~11 s、同驻留 ~2 × 7.45 GB。

## 2. 改动

### 2.1 xsynth-Lumino fork（`3fd31db`）

```rust
// core/src/soundfont/mod.rs
pub fn from_presets(
    presets: Vec<xsynth_soundfonts::sf2::Sf2Preset>,
    stream_params: AudioStreamParams,
    options: SoundfontInitOptions,
) -> Self
```

- 把 `new_sf2` 中「解析之后的构建」原样搬进 `from_presets`；
- `new_sf2` = `load_soundfont` + `from_presets`，行为不变；
- `Sf2Preset` 的采样是 `Arc<[f32]>`，因此两个消费方共享同一份采样数据。

### 2.2 lumino-rs

| 位置 | 改动 |
|---|---|
| `gpu-synth/soundfont/cache.rs` | 进程级 `Weak<Vec<Sf2Preset>>` 缓存（键 path/mtime/size/rate）+ 解析/命中计数 |
| `gpu-synth/soundfont/load.rs` | `load_core` 改走 `load_presets_cached`；`SoundFontCore.presets` 持有 `Arc` |
| `gpu-synth/soundfont/types.rs` | `SoundFontCore.presets: Option<Arc<Vec<Sf2Preset>>>` |
| `midi-io/soundfont_cache.rs` | SF2 走共享 presets + `SampleSoundfont::from_presets`；`PresetBackedSoundfont` 持有 `Arc` 防止 `Weak` 提前回收；SFZ 保持原路径 |
| `Cargo.toml` | xsynth 三件套 rev → `3fd31db` |

**生命周期**：presets 缓存是 `Weak`；消费方（`SoundFontCore` / `PresetBackedSoundfont`）
持有强引用，任一栈存活期间缓存不回收；两栈都释放后自动回收（不改变 014 的边界）。

## 3. 实测

### 3.1 共享解析（`cross_stack_shares_one_parse`）

| 音源 | presets 解析 | XSynth 构建 | XSynth 命中 | LGS core 构建 | LGS 命中 |
|---|---:|---:|---:|---:|---:|
| rich.sf2 | **1** | 15.1 ms | 17 µs | 2.44 ms | 52 µs |
| Jasmine 3.4 GB（debug） | **1** | 36.7 s（含只此一次的解析） | 33 µs | **8.85 ms**（原 29.6 s） | 108 µs |

- LGS 首次构建不再解析，只做 zone/矩阵构建（Jasmine 8.8 ms）；
- XSynth 的 36.7 s 是 debug 下**唯一一次**解析的成本（release ~5.7 s）；
- 命中均为微秒级。

### 3.2 逐位一致

- `rich.sf2` 512 filtered / unfiltered：`ea209e1f675b4d03` / `ba3ce4034c7b5298`
  （与改动前一致）。

### 3.3 测试

- `cross_stack_shares_one_parse`：断言 presets `(parse, hit) = (1, 1)`，
  XSynth `(build, hit) = (1, 1)`，LGS `(parse, hit) = (1, 1)`；
- `cargo test -p lumino-gpu-synth`：116 passed；fmt/clippy 零告警。

## 4. 边界

- **SFZ 不进 presets 缓存**：采样分散在多个文件，单文件 mtime 不能代表内容；
- **GPU 显存不跨 device 共享**：本卡只保证 CPU 侧一份；GPU chunk 仍由 007/014 管理；
- **跨进程共享不做**（014 边界）；
- 选 bank/preset 仍由每栈自己完成（presets 是全集，不改变选择语义）。
