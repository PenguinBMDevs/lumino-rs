## 0. 执行模型

- **一块 = 一批并行 subagent**；块内文件互不重叠，跨块串行。
- subagent 只写代码：禁止运行 `cargo` / `rustc` / `rustfmt` / `clippy` / `nextest` / rust-analyzer；
  禁止 commit / push；禁止新建文件、改 pub API、加 `#[allow]`、加 `unwrap/expect`。
- 验收由主 agent 统一执行：逐文件移动式 diff、字面量多重集、`cargo fmt`、受影响 crate
  `clippy --all-targets -D warnings`、`nextest`，通过后按块提交。
- profile：`~/.config/opencode/agents/rust-code-engineer.md`（运行时注入，因 opencode
  拒绝该 agent 作为 subagent 直接启动）；技能：`.opencode/skills/pua/SKILL.md`。
- 模型：`opencode-go/deepseek-v4.1-flash`。
