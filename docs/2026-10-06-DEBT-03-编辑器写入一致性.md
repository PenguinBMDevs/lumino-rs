# DEBT-03 编辑器写入一致性（#120）

> 来源：全仓屎山扫描 2026-10-06（分片 1 + 3）｜优先级 **P0** ｜类型：数据一致性 / tech-debt
> 总报告：`docs/2026-10-06-全仓屎山扫描-总报告.md`

## 背景

编辑器"写入路径"在三处失守：异步提交无轨守卫（**可整轨串写**）、UI 等待无超时
（**可占核挂死**）、插入失败被忽略（**静默丢音**）。这三条都直接动用户数据。

## 证据（file:line）

| 项 | 位置 | 说明 |
|---|---|---|
| **异步提交跨轨竞态** | `crates/editor/editor-state/src/.../async_commit.rs:56,115`、`crates/editor/ui-editor/src/track.rs:16`、`src/runner/menu/file.rs:225` | `PendingCommit` 不存 track_id，写回用轮询时 `current_track`；松手后切轨 → A 轨音符整轨写入 B 轨，无历史可 Undo |
| **UI 无超时忙等** | `crates/editor/ui-editor/src/impls/editor_impl/commit.rs:318-357` | `None => yield_now()` 自旋；worker panic/卡死 = UI 100% 占核 |
| **跨轨移动丢音** | `crates/editor/ui-editor/src/arrangement_ops/move_notes.rs:143,171-176` | 源已删、目标 `insert_note` 失败被忽略且无回滚 |
| MoveOp 丢音 + 恒真表达式 | `crates/editor/editor-state/src/.../history/ops.rs:130-144` | `deleted.min(inserted.max(deleted)) == deleted` 恒等 |
| Razor 忽略结果 | `crates/editor/ui-editor/src/arrangement_ops/razor.rs:116-117,145-149` | 失败仍计成功并广播（对端幻影音符） |
| Paste 计数错 | `crates/editor/ui-editor/src/clipboard/paste.rs:49-58`、`paste_interop.rs:171-206` | 按输入数计成功（忽略 `_ids`） |
| gfx 越界写 | `crates/editor/gfx/src/gpu_note_buffer/ops/upload.rs:55-84`、`internal.rs:33-92` | `grow()` 失败被忽略仍全量写 buffer |
| 性能 | `note_ops/selection.rs:158-179`（O(n²)）、`move_notes.rs:151-192`（写路径全扫）、`accessors/write.rs:313-328`（O(start)） | 详见分片报告 |

## 修复方案

1. `switch_to_track` 加 `has_pending_commit` 守卫（**立刻止血**）+ `PendingCommit` 记录 track_id 按轨写回；
2. `drain_async_commit` 超时降级（日志 + 丢弃 pending + `mark_notes_changed`）；
3. 所有 `insert_note*` 检查返回值：失败回滚已删项 + 回退该批历史 + 不计成功/不广播；
4. 性能项按分片路线图分批（选择缓存复用、区间扫描、`iter_window`）。
