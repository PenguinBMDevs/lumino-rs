# DEBT-06 协作与云健壮性（#123）

> 来源：全仓屎山扫描 2026-10-06（分片 4 + 6）｜优先级 **P1** ｜类型：健壮性 / 网络
> 总报告：`docs/2026-10-06-全仓屎山扫描-总报告.md`

## 背景

协作与云在网络异常路径上"静默失败"：断连无事件、重连只有配置没有实现、
云操作无重试/无超时，且云全局锁跨网络 IO 持有会冻结 UI。

## 证据（file:line）

| 项 | 位置 | 说明 |
|---|---|---|
| 云锁跨 IO 卡 UI | `src/runner/cloud.rs:30-34,184`、`cloud_status.rs:91-106`、`cloud_ops.rs:26-27`、`cloud_files.rs:22`、`cloud_save.rs:109-110` | 后台全程持锁；UI 线程 `lock_cloud()` 无 `try_lock` |
| 协作连接竞争 | `src/services/collaboration_service.rs:100-122,152-159,326-340` | 在途 client 移出 Mutex，二次 connect 互相覆盖；disconnect 后"复活" |
| 断连静默/重连缺失 | `crates/network/collaboration/src/client/connection.rs:161-177`；`event.rs:12`（Disconnected 无人发）；`lib.rs:28`、`types/client.rs:19,36`（参数无消费） | `collaboration_service.rs:91-92` 却置 `true/5` |
| 云无重试/无超时 | `crates/network/cloud/src/manager.rs:100-124,169-245`；`ftp.rs:66-88`；`sftp.rs:71-77` | 全仓 `retry|backoff` 0 命中；仅 WebDAV 有超时 |
| HTTP 无超时 + 2× 内存 | `crates/network/collaboration/src/http.rs:60-71,159-175` | 分片 6 M3 |

## 修复方案

1. 后台操作维护无锁快照（`RwLock/ArcSwap`），UI 只读快照；
2. `ClientSlot{Idle/Connecting(token)/Connected}` + generation，token 不匹配不提交；
3. 断连 emit `Disconnected`；实现重连或摘除误导字段/参数；
4. FTP/SFTP 设读写超时；幂等读加有限退避重试；HTTP 加超时。

## 任务拆解

- [ ] 云状态快照化（UI 无锁读）+ 冻结复现测试
- [ ] 协作 client 槽位状态机 + 并发 connect 测试
- [ ] 断连事件接线 + 重连决策（实现或移除配置）
- [ ] FTP/SFTP 超时 + 重试（幂等读）

## 验收

- [ ] 传输中打开设置页/云面板不冻结
- [ ] 断连有可见事件；并发 connect 不互相覆盖
- [ ] 死连接在超时内失败、可重试
