# REND-002-GPU 多端口渲染支持（#87）· 行动方案 v2

> 分支：`feat/rend-002-gpu-multi-port`（基于 dev `43ca4ed9`）
> **范围（2026-10-03 用户拍板）**：本轮**只做离线渲染**（导出）；实时 LGS 后续。
> 路线：**先解锁**（写死→可配，单端口零行为变化）→ 离线多端口落地 → PC/打击乐对齐 CPU。
> 参照 CPU（REND-002 #86 Phase 1/2），**不要求复用代码**（两条管线不同）。

## 一、目标

把 GPU 离线链路"16 通道硬编码"扩为 **N×16 全局通道空间**（N=实际使用端口，上限 16），
`(port, ch) → eff(port)*16+ch`；CC/PC/PB/声部/mix 状态按全局通道隔离；
`ProgramChange` 行为对齐 CPU（单 SF2 内 preset 选择；**不含**多 Port 多音色库 = #88）。

## 三、路线（U → L → T；R 本轮不做）

### U. 解锁（零行为变化；单端口恒等）
- **U0 事件编码**：`channel(8)|kind(4)|payload(20)`（payload 实际 ≤16bit）；三处手工打包统一走构造函数；`send_event` 去 `.min(15)`。LGS 掩码保留（ch<16 不受影响）。
- **U1 通道空间**：`SynthConfig` 新增 `midi_channels: usize`（默认 16；validate 16 倍数、16..=256）；
  `channels/key_voices/spawn_budget/active_notes/warm 位图` 按 `midi_channels*128` 分配（固定数组改 `Vec<u32>`）；
  越界 `ch >= midi_channels` 丢弃+一次性告警。
- **U2 端口原语 + 解析**：gpu-synth 内镜像 `midi-model::multi_port` 语义（不引依赖）：
  `TrackStream` 捕获首个 FF 21；`MidiStream` 打包点做全局映射；`MidiFile::parse` pass1 收集每轨 port；
  `MidiFile::max_port()`。单端口无 FF 21 → 恒等。
- **U3 导出接线**：`build_export_data` 写 `midi_port`；`build_synth_config` 传 `midi_channels = channels_for_max_port_clamped`。
- **判定**：解锁 = 机械改造（上表 A–D），量级与 CPU Phase 1 相当，**不开新卡**，留在 #87。

### L. 离线多端口落地
- 删除 `warn_gpu_multi_port` 两处调用与函数（保留 `warn_port_overflow`）。
- 测试：打包 roundtrip 0..=255；FF21→global 映射（复用 `export/tests/multi_port_render.rs` 的 fixture 生成器）；
  引擎隔离（ch16 的 CC/音符不影响 ch0）；双端口导出 e2e。
- 验收（卡片口径，离线部分）：Night Voyager 7 端口 CPU vs GPU A/B（手动）；单端口素材回归；
  导出耗时/内存对比（#94 基线）。

### T. ProgramChange/打击乐对齐 CPU（单 SF2 多 preset；独立 PR，**建议开新卡**）
- SoundFont：保留全量 preset（`load_soundfont` 已返回全部），按 `(bank,preset)` 惰性构建 zone 矩阵；
  `zones_at(key, vel, bank, preset)`。
- `ChannelState`：`bank`/`preset`/`percussion`；CC0/CC32 bank select、ProgramChange、CC121 语义按 fork 镜像
  （`params.rs:60-91`、`channel_sf.rs:55-114`）；ch9 各端口默认打击乐（对齐 CPU 显式 `p*16+9`）。
- 模板缓存 key 增加 `(bank,preset,percussion)`。
- **不含**多 Port 多音色库（#88）。
- **注意**：落地后单端口 ch9 从"当前 GPU 音色"变为"鼓组"——这是**对齐 CPU 的行为变化**，
  回归口径改为对 CPU A/B，而非旧 GPU 输出。

### R. 实时 LGS（本轮不做）
- `LgsOutputConn` 去掩码 + `Lgs::set_midi_port_layout` 重建管线；留 #87 后续或单独卡。

## 四、验收（本轮 = 离线）

1. 单元：packing roundtrip；FF21 映射；通道隔离；配置 validate。
2. 导出 e2e：双端口 fixture；单端口恒等（U/L 阶段输出应与现状一致）。
3. 手动：Night Voyager 7 端口 CPU vs GPU（L 阶段先看通道隔离；T 阶段看音色/打击乐一致）。
4. 性能：多端口导出耗时/内存不劣化；单端口路径成本不变（#94 底线）。

## 六、风险

- 事件布局横跨 parser/stream/events → U/L 阶段必须单端口 bit-exact 回归。
- 256 通道内存/性能只允许多端口支付；单端口保持 16 通道成本。
- T 阶段 SoundFont 多 preset 矩阵内存（大 SF2 需评估）；ch9 行为变化需用户听感确认。
