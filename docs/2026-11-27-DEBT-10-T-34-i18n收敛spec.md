# DEBT-10 / T-34：i18n 双体系收敛 spec

> 日期：2026-11-27
> 状态：spec 已定，迁移待排期
> 关联：`2026-11-26-DEBT-10-结构减法与尺寸治理.md`、T-12

## 1. 现状

| 体系 | 位置 | 规模 | 使用方 |
|---|---|---|---|
| catalog + `tr!` | `crates/core/core/src/i18n/catalog/*` | 14 个分片文件 + `catalog.rs`（496 行） | 23 个文件（UI / ui-egui / tests） |
| extras i18n | `crates/tools/extras/src/i18n/{translations,settings}.rs` | 334 + 335 行 | `ui-core`（button_descs / help / sidebar_event）、`ui-settings`、`ui` |

两套都能产出中文 / 英文文案，新增一条文案时无法从类型上判断该放哪边，于是同一概念出现两份。

## 2. 规则（立即生效）

1. **运行期 UI 文案只进 catalog**：新增 `tr!` 字面量必须登记在
   `i18n/catalog/<域>.rs`，由 `catalog.rs` 的字面量门禁守护。
2. `lumino_extras::i18n` **冻结**：只允许修 bug，不新增词条；新需求一律走 catalog。
3. 设置页的结构化标签（`settings.rs` 里的 `SettingsLabels` 等）如果必须保留类型，
   数据从 catalog 取，不再自带一份中英文常量表。
4. 一个概念只允许一个 key；中英文同 key 的分片文件按域归属（shell / view / settings / …）。

## 3. 迁移顺序

1. 盘点 `extras/i18n` 的公开符号与调用点（`git grep` 已列 9 个文件）。
2. 把 `translations.rs` 的词条逐条搬进 catalog 对应域分片；用脚本比对 key 集合，
   保证零遗漏。
3. `settings.rs` 改为从 catalog 取值；调用点只换数据源，不改 UI 结构。
4. 删除 `extras/i18n` 与 `extras` 对它的 re-export，`cargo check` 清零。
5. 在 `catalog.rs` 增加守护测试：`tr!` 字面量必须存在；不允许出现第二张中英映射表。

## 4. 验收

- 新增一条文案只改 1 个 catalog 分片（+ 如新增 key 需登记 1 处）；
- `rg "translations.rs|SettingsLabels" crates/tools/extras` 为空；
- `cargo nextest run -p lumino-core -p lumino-ui-core` 绿。
