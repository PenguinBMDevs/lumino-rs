## 1. 交付内容

「设置 → 关于」页**最后一个文本内容下方**新增灰阶小字彩蛋「回声洞」：

- **进入动效**：进入关于页即以**打字机效果**逐字显示当前文案（20 字符/秒；`dt` 上限钳 50ms，卡顿后不瞬移）；
- **切换动效**：单击彩蛋文本 ⇒ 当前内容**闪烁 0.5s**（0.125s 半周期方波 = 2 个完整明暗循环）退出 ⇒
  下一条以打字机效果进入，索引**循环**（走完 5 条回到第 1 条）；
- **连点安全**：闪烁期内的点击**一律忽略** ⇒ 每次点击最多推进一条，且任何时刻最长 0.5s 必然离开闪烁相位；
- **内容内置**：文案为编译期常量 `ECHO_TEXTS`（5 条，含 `🐧`），不读配置、不依赖外部文件、不做本地化；
- **局部可用性保障**：闪烁用 alpha（零重排）+ `width(Fill)`/`height(Fixed)` 容器（命中区与行高恒定）。

## 3. 关键设计决策

1. **状态放 `RootState`，不放 `SettingsPanel`**：`Root::apply_settings` 末尾是**整面板替换**
   （`ui/src/root/editor_ops/dialog/settings.rs`）。放面板内 ⇒ 关面板瞬间把闪烁中的瞬时状态搬进主窗口，
   而主窗口同样跑 `frame.rs` 门控与 `handle_animation_tick` ⇒ 为一段与它无关的动画持续全窗重绘。
2. **起始相位 `Idle` + `MenuSelected` 装填**：设置面板每次打开都会重建 `RootState`
   （`Host::new_settings_dialog`）。若开局即 `Typing`，主窗口的同一状态也会被门控选中，
   APP 启动后主窗口空转重绘约 1 秒。故初始不动、进关于页才装填；重复进入 = 重播。
3. **连点语义钉死为「闪烁期忽略点击」**（调研 §4-P0-4 的三选一）：这是唯一能同时保证
   「每次最多推进一条」与「有界离开闪烁」的语义。另两种直觉写法分别导致饿死与跳条，均有单测反证。
4. **闪烁用 alpha 而非隐藏控件**：隐藏会把行高/宽度交回布局重算，闪烁期间整页上下呼吸；
   alpha=0 保留布局盒，零重排。iced `Text` 无 `.opacity()`，故经 `.style()` 闭包捕获 alpha 实现。
5. **逐字揭示在 `update` 内缓存，`view` 保持只读纯函数**：`Root::view(&self)` 无法推进状态；
   顺带消除每帧一次 `String` 分配。截取按 `chars().take(n)`——文案含 3 字节 CJK 与 4 字节 emoji，
   字节切片会在非 char 边界 panic。
6. **硬超时：不需要**。打字与闪烁都是单调有界的定时相位（最长 ≈ 0.5s + 文案长/20cps ≤ 1.3s），
   与 UI-007 多相位比值推进不同；「有界性」改由单测锁定（见 §5）。

## 4. 落地陷阱（研究阶段未预判）

| # | 陷阱 | 现象 | 处置 |
|---|---|---|---|
| G1 | **`cargo clippy --workspace --all-targets` 会编译 gitignored 的 `examples/`** | 探针文件（`.gitignore` 忽略）触发 `clippy::print_literal`，**把本地/CI 门禁弄红** | 修掉探针内的字面量格式串（`{:<8} … []` 内联进格式串）。留档：**gitignore 不参与 cargo 的目标发现**，草稿探针一样要过 lint |
| G2 | **单测里「一次大步推进时间」会被 `dt` 上限拦下** | 4 个单测误报失败（如 `now += 520ms; update()` 只推进 50ms，闪烁未结束） | 加 `advance_for()` 辅助按 ≤16ms 分帧推进。**这反证了 `dt` 钳制确实生效**——不是实现 bug，是测试构造 bug |
| G3 | **`view()` 返回的 `Element` 会与同一状态的可变借用冲突** | `pages/about.rs` 测试里 `let _element = view(..)` 未收窄作用域 ⇒ `E0502`（`_element` 的析构在作用域末尾） | 每次渲染用 `{ let _element = view(..); }` 独立成块。UI-007 的测试恰好每次都在块内，故未暴露 |
| G4 | **`clippy::manual_is_multiple_of`（Rust 1.98）** | `half_periods % 2 == 0` 直接红 | 改 `half_periods.is_multiple_of(2)` |
| G5 | **20cps 下第一个字符需 50ms**，与人眼直觉不符 | 接线测试用 20ms `sleep` 后断言「已有字符」⇒ 误报 | 断言改为**有界帧数**内出现字符，不钉死具体时长 |
| G6 | **被编辑的文件被写成了全 CRLF** | `components/constants.rs` 工作副本 70 行全 CRLF，而 HEAD blob 是纯 LF（`git diff` 因 `* text=auto eol=lf` 归一化仍只显示 4 行插入，**不报错但会持续打印警告**） | 将该文件归一化为 LF（内容零改动：diff 前后均为 **4 插入 / 0 删除**）。扫描 400 个已跟踪 `.rs` 另发现 1 个历史 CRLF 文件（`crates/core/message/src/batch_edit.rs`），**非本卡范围，未触碰** |

## 6. 已知近似与遗留

| # | 项 | 说明 |
|---|---|---|
| L1 | 视觉观感需人工验收 | 自动化只覆盖逻辑与接线；打字速度（20cps）、闪烁节奏（0.5s / 2 个明暗循环）、emoji 与 12px 中文的**基线对齐**观感需实机目视 2 秒后可一行常量调整 |
| L2 | 「非动画期无常态重绘」需实机确认 | 设计上：起始 `Idle`、收尾回 `Idle`、`needs_animation` 只在 `is_animating()` 为真时命中；`test_every_phase_reaches_non_animating_within_bound` 锁定有界性。仍未做 puffin/FPS 实测 |
| L3 | 极早期点击会先补全当前文案 | 前缀为空时点击 ⇒ 先显示全文再闪烁。取舍：避免「闪烁空字符串」被观感解读为「点击无反应 0.5s」（调研 §8-Q4 记录，采用了最小偏离方案） |
| L4 | 重复进入关于页会重播当前文案 | 由 `MenuSelected(MENU_INDEX_ABOUT)` 装填决定；卡面「进入时以打字机效果逐字显示」的字面语义 |
| L5 | 探针文件不入库但留在工作区 | 它会让 `cargo clippy --all-targets` 编译它（已修到干净）。如需彻底消除该编译项，删除 `crates/audio/note-core/examples/echo_glyph_probe.rs` 即可（零代码依赖） |
| L6 | 换关于页菜单索引需同步常量 | `MENU_INDEX_ABOUT = 9` 与 `lib.rs` 的匹配分支同源；菜单项增删时会偏，由 L2 类护栏之外的**人工**注意（`test_default_menu_index_is_not_about` 只守初始页语义） |
