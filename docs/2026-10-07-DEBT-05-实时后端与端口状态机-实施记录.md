## 二、行为与语义

- 端口编辑：UI 立即返回，150ms 停手后在后台重建；连续点按只落一次（或至多一轮追赶）。
- 装载/关闭/导出/重初始化：保持同步语义，但先等后台在途任务收尾（正常无在途 → 零等待）。
- 应用失败：保持旧布局，`spawned` 不回写，`desired` 保留待下次事件触发（与 REND-002 原语义一致）。
- 后台重建期间 `api` 由 worker 持有；期间任何需要 API 的同步入口都会 drain 等待，不会因 `api == None` 静默失败。
