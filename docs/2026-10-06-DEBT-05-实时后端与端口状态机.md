## 背景

Runner 的 `midi_manager`（desired/spawned/active 布局状态机）是 REND-002/REND-010
的核心枢纽，却**零单测**；端口布局重建在 UI 线程同步执行（200–300ms 卡顿）；
`WindowEvent` 存在死变体与 `_ => {}` 静默吞事件。

## 修复方案

1. 抽纯函数状态机（装载暂存 / 完成对齐 / 切换交错 / 失败保留 / 关闭归零）
   + 6–8 单测，不依赖音频设备；
2. 布局重建挪后台串行队列 + 150ms 防抖，完成回传事件（与 UI 无锁解耦）；
3. 清理死变体或显式处理；`_ => {}` 改 `tracing::warn!`。
