# UI-015：音符总量统计显示（工程设置面板 / 下边栏双位置可切换）（Issue #70）

> 记录日期：2026-09-26 ｜ 分支：`feat/ui-015-note-count` ｜ PR：#77
> 关联：UI-014（#55，工程设置对话框数据注入）本卡在其数据链路上扩展

## 背景

工程音符总量此前无处可看。Issue #70 要求：在「工程设置面板」与「下边栏」两个位置之一
显示音符总量（只读、带千分位），位置可配置、即时生效、重启保留；两位置互斥；
编辑期间数值实时更新。

设计取舍（用户确认方案 A）：

1. **默认「工程设置面板」**：不改变下边栏现有观感（默认不出现新元素）；
2. **下边栏模式下顶替「就绪」**：空闲时显示音符总量，但**不顶替**悬停按钮解释与显式
   状态消息（保存提示等），即优先级链：`悬停解释 > 状态消息 > 音符总量 > 就绪`；
3. **两位置互斥**：`ProjectSettings` 模式 → 对话框显示该行、状态栏保持「就绪」；
   `StatusBar` 模式 → 反之（对话框不显示该行），避免同屏重复。

实现要点：

- **数据源复用** `Host::get_editor_note_count()`（O(轨道数) 求和），不新增计数维护逻辑，
  避免与既有编辑路径产生双源不一致；
- **实时刷新**：对话框打开期间由 Runner 每帧读取主窗口计数并推送，**值变化才置脏**，
  避免每帧无效重绘；编辑（画/删/undo/加删轨）即刻反映；
- **悬停/消息优先**：音符总量只占左侧链最低位，消息超时后自动恢复。
