## 一、本阶段交付

### 1. 入口推导 `midi_max_port`（流式 / 内存两条路径）

- `render_audio`（流式）：`StreamingMidiPlayer` 预扫描已提取每轨 FF 21，
  渲染入口 `config.midi_max_port = player.max_port()` 后克隆配置下发；
- `render_audio_from_document`（内存）：`config.midi_max_port = doc.max_port()`；
- UI（`audio_export.rs`）不再感知端口，统一由渲染入口推导（B3：避免耦合）。

### 2. 合成层通道与打击乐

- `AudioRenderConfig::synth_format()`：0 → `SynthFormat::Midi`（零行为变化）；
  否则 `Custom { channels: (min(max_port,15)+1)*16 }`（≤256）。
- `AudioRenderConfig::percussion_channels()` + `AudioEngine::new`：fork 的
  `Custom` 不自动开 ch9 打击乐（仅 `Midi` 自动，`channel_group/mod.rs:77-81`），
  多端口时对每个端口的 `p*16+9` 显式 `SetPercussionMode(true)`（含 port 0）。

### 3. 事件映射与超限口径（B1）

- `global_event_channel(config, port, ch)` 纯函数：单端口恒等且忽略端口；
  多端口 `(effective_port(port), ch) → port*16+ch`；
- 超上限端口（>15）折叠到端口 15 块：装载时告警（列出超限轨道，最多 20 条 +
  计数），渲染结束汇总“折叠事件数”，**不静默丢音、不整体拒绝**。

### 4. 回归证据

- 纯函数单测：`single_port_is_identity_and_ignores_port`、
  `multi_port_maps_to_port_blocks`、`over_limit_port_folds_to_last_block`；
- 配置单测：`synth_format`（Midi / 112 / 256）与 `percussion_channels`（空 / 每端口 ch9 / 折叠 16 端口）；
- 自动 fixture（`crates/tools/export/tests/multi_port_render.rs`，不依赖外部素材/音色库）：
  - `multi_port_document_enables_custom_channels`：双端口 SMF（跨端口同 ch0/key60）→
    `max_port=1`、`Custom{32}`、打击乐 `[9,25]`；
  - `single_port_document_keeps_midi_baseline`：无 FF 21 → `Midi` + 空打击乐列表。
- 全量：`cargo test -p lumino-export -p lumino-midi-io -p lumino-midi-model -p lumino-midi-loader`
  全绿；`cargo check/clippy --workspace --all-targets`、`cargo fmt` 无告警。
