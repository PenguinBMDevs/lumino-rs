**关键判读**（与 UI-007 一致，逐条已被其落地证伪/证实）：

- 对话框**没有**周期性命中（主窗口有每 `MonitorRefreshInterval` 一次的 `PerfUpdate`，对话框没有）⇒ 不能指望"顺带被弄脏"。

## 4. 卡面需澄清 / 修正项

### P0-1（忽略即「动画冻结在 1~2 帧」，验收 2、3 直接不通过）
**只改 `frame.rs` 的 `needs_animation` 门控是不够的。**
- 修正（与 UI-007 完全同款，无需改 `dialog` crate）：
  1. `frame.rs` 门控加入 `echo_cave.is_animating()`；
  2. 同一分支内 `if echo_cave_animating { self.ui_dirty = true; }`（先例：同文件 `:102-104` 的 `about_egg` 分支）。
- UI-007 的调研曾建议「提取 `Host::needs_animation()` + 改 `DialogManager` 走 `redraw_force()`」，落地后被证伪为不必要（其调研 §3.5-F1）⇒ **本卡不重复该弯路**。

### P0-2（忽略即「主窗口无谓逐帧重绘」+ 关面板后动画串场）
**状态**不能**放 `SettingsPanel`。**
- 证据：`ui/src/root/editor_ops/dialog/settings.rs:24` 是 `self.settings = new_settings;`——**整面板替换**。若回声洞状态在面板内：
  - 关闭设置面板瞬间，闪烁中的 `EchoCaveState` 被复制进**主窗口** Root；
  - 主窗口同样执行 `frame.rs` 门控与 `handle_animation_tick` ⇒ 主窗口会为一段与它无关的动画持续全窗重绘，违背「关于面板现有内容与布局不受影响」与仓库的重绘纪律；
  - 另外 `SettingsPanel` 是「配置镜像」（`apply_settings` 逐字段 diff 同步，`settings.rs:50-252`），塞入视图动画状态属分层污染。
- 修正：新增 `ui-core/src/state/echo_cave.rs` + `RootState::echo_cave` 字段（照抄 `about_egg` 的位置：`ui/src/state/root_state.rs:113-118,157`）。

### P0-3（忽略即「彩蛋永不出现」，验收 1 通过但 2 不通过）
**「进入时打字机」需要一个显式装填点。**
- 事实：`SettingsPanel::new` 硬编码 `selected_menu_index: 0`（`panel.rs:47`），**不读配置**；关于页索引 9 是裸魔数（`lib.rs:277`）⇒ 关于页**永不是初始页**，「渲染到关于页」这件事只能通过 `Event::MenuSelected(9)` 到达。
- 若把 `EchoCaveState::new()` 初始相位设为 `Typing`（"开局就打字"），会连带产生 P0-2 的反面问题：**主窗口 RootState 也处于 Typing**，导致 APP 启动后主窗口空转重绘 1~2 秒。
- 修正（推荐）：
  1. `EchoCaveState::new()` 起始相位 = **`Idle` 且 `revealed` 为空**（`is_animating() == false`）；
  2. 在 `ui/src/root/handlers/settings.rs` 增加 arm：`Event::MenuSelected(MENU_INDEX_ABOUT) => root.state.echo_cave.begin_typing(Instant::now())`（**必须在现有 `root.settings.update(event.clone())` 之后/之旁**，`:31`）；
  3. `ui-settings` 导出 `pub const MENU_INDEX_ABOUT: usize = 9;`，`lib.rs:277` 的匹配分支改用它 ⇒ 消灭裸魔数漂移（「还有什么没想到的」项）；
  4. 加护栏单测：`SettingsPanel::new(..).selected_menu_index != MENU_INDEX_ABOUT`——若将来有人把关于页设为默认页，此测试变红，提示必须在 `view` 路径补装填（§6）。

### P0-4（忽略即「快速连点卡死或跳条」）
**连点语义必须钉死。** 三种候选：

| 方案 | 行为 | 判决 |
|---|---|---|
| A｜闪烁期**忽略**点击 | 点击只在 `Typing`/`Idle` 生效；`Blinking` 期间一律吞掉 ⇒ 每次点击最多推进 1 条，且**最长 0.5s 必达下一状态** | ✅ **推荐**（可证单调、无饿死） |
| B｜闪烁期**重置**闪烁计时 | 连点（如 20 次/秒）会把闪烁窗口无限推迟 ⇒ **观感卡死**，直接违反验收 4 | ❌ |
| C｜闪烁期**立即推进** | 连点会一次跳过条文案（10 次连点 = 10 条），且 `Blinking` 相位形同虚设 | ❌ |

⇒ 采用 A，并用单测锁死：`Blinking` 内连点 50 次，仍必须在 ≤ `BLINK_DURATION` 内进入 `Typing`，且 `index` **恰好 +1**。

### P1-1（忽略即「闪烁做不出」）
`iced_widget::Text` 无 `.opacity()`；`.color(impl Into<Color>)` 需要具体值而颜色来自主题 ⇒ 只能走 style 闭包。
- 修正：在 `ui-settings/src/components/styles.rs` 新增（该文件已有同构工厂）：

```rust
/// 回声洞文本样式：占位灰 + 可调不透明度（闪烁用）
pub fn create_echo_text_style(opacity: f32) -> impl Fn(&Theme) -> text::Style + 'static {
    let opacity = opacity.clamp(0.0, 1.0);
    move |theme: &Theme| {
        let mut color = theme.extended_palette().background.weak.text;
        color.a *= opacity;
        text::Style { color: Some(color) }
    }
}
```

> **为什么用 alpha 而不是「隐藏控件」**：隐藏会把行高/宽度交给布局重算，闪烁期间整页会上下呼吸；alpha=0 保留布局盒，**零重排**（与 UI-007 用「左右定宽占位器」表达晃动位移是同一个纪律）。

### P1-2（忽略即 panic 或分层污染）
- **禁止字节切片**：文案 `"企鹅路过。🐧"` 的 🐧 是 4 字节、CJK 是 3 字节，`&s[..n]` 在 n 落于字符中间时 panic。必须 `chars().take(n).collect::<String>()`。
- **禁止在 `view` 里推进状态**：`Root::view` 只读（UI-007 调研 §P1-1 记录），且 `view` 是纯函数以便测试。⇒ 已揭示前缀在 `update()` 内维护到 `EchoCaveState.revealed: String`，`view` 只读 `.text()`（顺带消除每帧一次 `String` 分配）。

### P1-3（忽略即「命中区随打字缩水」与「首帧塌陷」）
- `mouse_area` 的命中盒 = 子元素布局盒。若直接 `mouse_area(text(&revealed))`：打字第 1 帧只有 1 个字宽，用户想"点一下"几乎点不中。
- `text("")` 的布局高度需按 iced 语义确认；稳妥做法不赌：外包一层
  ```rust
  mouse_area(
      container(text(echo.text()).size(ECHO_TEXT_SIZE).style(create_echo_text_style(echo.opacity())))
          .width(Length::Fill)              // 命中区 = 整行宽
          .height(Length::Fixed(ECHO_ROW_HEIGHT))  // 行高恒定，不受揭示进度影响
          .align_y(Alignment::Center)
  )
  .on_press(Message::Settings(Event::EchoCaveClicked))
  .interaction(mouse::Interaction::Pointer)  // 手型光标（iced_winit:515 已验证映射）
  ```

## 5. 实施方案（文件级）

### 5.1 状态机（**新** `crates/editor/ui-core/src/state/echo_cave.rs`）

```rust
/// 内置彩蛋文案（写死，索引循环切换；卡面 §默认内置文案）
pub const ECHO_TEXTS: [&str; 5] = [
    "你发现了回声洞。",
    "喂——！……（回音：喂——！）",
    "这里什么都没有，只有回声。",
    "每一个音符，都有回音。",
    "企鹅路过。🐧",
];

/// 逐字揭示速度（字符/秒）
pub const ECHO_CHARS_PER_SECOND: f32 = 20.0;
/// 闪烁退出总时长（秒）——卡面要求 0.5s
pub const ECHO_BLINK_DURATION: f32 = 0.5;
/// 明暗半周期（秒）：0.5s / 0.125 = 4 个半周期 = 2 个完整明暗循环
const ECHO_BLINK_PERIOD: f32 = 0.125;
/// dt 上限（秒）：卡顿/断点后不瞬移（与 about_egg 同款纪律）
const MAX_DT: f32 = 0.05;

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum EchoPhase {
    /// 空闲：尚未装填，或本次打字已完成（不要求逐帧驱动）
    Idle,
    /// 打字机：逐字揭示中
    Typing,
    /// 闪烁退出：当前内容闪烁 ECHO_BLINK_DURATION 后切换下一条
    Blinking,
}

#[derive(Debug, Clone)]
pub struct EchoCaveState {
    index: usize,            // 当前文案索引
    phase: EchoPhase,
    phase_elapsed: f32,
    last_update: Option<Instant>,
    revealed: String,        // 已揭示前缀（update 内维护，view 只读）
}
```

API（全部时间由外部注入 `Instant`，便于无 `sleep` 单测）：

| 方法 | 语义 |
|---|---|
| `new() -> Self` | `Idle` / `revealed` 空 / `is_animating() == false`（**P0-3 的前提**） |
| `begin_typing(now)` | 进入关于页时调用：相位 → `Typing`、计时归零、`revealed` 清空（**重复调用 = 重播**） |
| `on_click(now) -> bool` | `Typing`/`Idle` ⇒ 进 `Blinking`（`revealed` **冻结**）、返回 `true`；`Blinking` ⇒ **忽略**、返回 `false`（P0-4 方案 A） |
| `update(now) -> bool` | 推进；返回是否仍需逐帧驱动 |
| `text() -> &str` | `&revealed` |
| `opacity() -> f32` | `Typing`/`Idle` ⇒ `1.0`；`Blinking` ⇒ 方波 `0.0/1.0`（**结束时刻落在暗态**，与"下一条从空字符串开始打字"无闪白衔接） |
| `is_animating() -> bool` | `Typing \| Blinking` |
| `index() -> usize` / `phase() -> EchoPhase` | 测试与日志用 |

`update` 主循环：

```rust
let dt = /* now - last_update，min(MAX_DT)（同 about_egg.rs:358-362） */;
self.phase_elapsed += dt;
match self.phase {
    EchoPhase::Typing => {
        let total = ECHO_TEXTS[self.index].chars().count();
        let n = (self.phase_elapsed * ECHO_CHARS_PER_SECOND) as usize;
        self.revealed = ECHO_TEXTS[self.index].chars().take(n).collect();   // 非字节切片（P1-2）
        if n >= total { self.phase = EchoPhase::Idle; return false; }        // 有界收尾
    }
    EchoPhase::Blinking => {
        if self.phase_elapsed >= ECHO_BLINK_DURATION {
            self.index = (self.index + 1) % ECHO_TEXTS.len();               // 循环
            self.phase = EchoPhase::Typing;
            self.phase_elapsed = 0.0;
            self.revealed.clear();
        }
    }
    EchoPhase::Idle => return false,
}
true
```

> 可选（§8-Q4）：`on_click` 时若 `revealed.is_empty()` 先补全全文再闪烁——避免「闪烁空字符串」被观感解读为"点击无反应"。
