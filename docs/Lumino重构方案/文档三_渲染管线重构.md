# Lumino 重构方案 —— 文档三：渲染管线重构

> 目标：消除 27 处重复 pipeline 创建代码，建立统一渲染抽象

---

## 一、当前问题诊断

### 1.1 Pipeline 创建代码重复

`crates/editor/gfx/src/` 下 6 个 renderer，每个都手写完整的 pipeline 创建：

| Renderer | Pipeline 创建位置 | 代码行数 | 重复度 |
|----------|------------------|---------|--------|
| arrangement_renderer | `init.rs:46-70` | ~25 | 90% |
| cc_bar_renderer | `core.rs:132-155` | ~25 | 90% |
| keyboard_renderer | `renderer/init.rs:31-55` | ~25 | 90% |
| miditrail_renderer | `pipeline.rs:83-110` | ~28 | 85% |
| note_renderer | `pipeline.rs:117-140` | ~24 | 90% |
| ruler_renderer | `core.rs:138-162` | ~25 | 90% |

**共同模式**：
```rust
// 每个 renderer 都包含以下代码（几乎完全相同）
let pipeline_layout = device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor {
    label: Some("xxx_pipeline_layout"),
    bind_group_layouts: &[...],
    push_constant_ranges: &[],
});
let pipeline = device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
    label: Some("xxx_pipeline"),
    layout: Some(&pipeline_layout),
    vertex: wgpu::VertexState { module: &shader, entry_point: Some("vs_main"), buffers: &[...] },
    fragment: Some(wgpu::FragmentState { module: &shader, entry_point: Some("fs_main"), targets: &[...] }),
    primitive: wgpu::PrimitiveState::default(),
    depth_stencil: None,
    multisample: wgpu::MultisampleState::default(),
    multiview: None,
    cache: None,
});
```

### 1.2 GPU 资源追踪手动化

`gpu_resource_tracker.rs` 提供全局函数：
```rust
pub fn add_texture(texture: &wgpu::Texture);
pub fn sub_texture(texture: &wgpu::Texture);
pub fn add_buffer(buffer: &wgpu::Buffer);
pub fn sub_buffer(buffer: &wgpu::Buffer);
```

**问题**：
- 每个 renderer 在创建 buffer/texture 时手动调用 `add_*`
- 每个 renderer 在销毁时手动调用 `sub_*`
- 漏调用会导致内存统计偏差（无法发现真实泄漏）

### 1.3 Renderer 之间无共享抽象

6 个 renderer 各自独立：
- 各自的 `init.rs` 或 `core.rs`
- 各自的 `prepare.rs` 或 `update.rs`
- 各自的 `draw.rs` 或 `render.rs`
- 各自的 `types.rs`（顶点定义）

没有统一的 `Renderer` trait 或基类。

### 1.4 Shader 管理分散

每个 renderer 有自己的 shader 文件（`.wgsl`），但加载逻辑分散在各 `init.rs` 中：
```rust
let shader = device.create_shader_module(wgpu::ShaderModuleDescriptor {
    label: Some("xxx_shader"),
    source: wgpu::ShaderSource::Wgsl(include_str!("xxx.wgsl")),
});
```

## 二、重构方案

### 2.1 PipelineBuilder 抽象

```rust
// lumino-gfx/src/pipeline.rs

/// 渲染管线构建器
/// 
/// 封装 wgpu::RenderPipeline 的创建逻辑，自动注册到资源追踪器。
pub struct PipelineBuilder<'a> {
    device: &'a wgpu::Device,
    label: &'a str,
    shader: &'a wgpu::ShaderModule,
    vertex_entry: &'a str,
    fragment_entry: Option<&'a str>,
    bind_groups: Vec<&'a wgpu::BindGroupLayout>,
    vertex_buffers: Vec<wgpu::VertexBufferLayout<'a>>,
    targets: Vec<Option<wgpu::ColorTargetState>>,
    primitive: wgpu::PrimitiveState,
    depth_stencil: Option<wgpu::DepthStencilState>,
}

impl<'a> PipelineBuilder<'a> {
    pub fn new(
        device: &'a wgpu::Device,
        label: &'a str,
        shader: &'a wgpu::ShaderModule,
    ) -> Self {
        Self {
            device,
            label,
            shader,
            vertex_entry: "vs_main",
            fragment_entry: Some("fs_main"),
            bind_groups: Vec::new(),
            vertex_buffers: Vec::new(),
            targets: Vec::new(),
            primitive: wgpu::PrimitiveState::default(),
            depth_stencil: None,
        }
    }

    pub fn vertex_entry(mut self, entry: &'a str) -> Self {
        self.vertex_entry = entry;
        self
    }

    pub fn fragment_entry(mut self, entry: &'a str) -> Self {
        self.fragment_entry = Some(entry);
        self
    }

    pub fn no_fragment(mut self) -> Self {
        self.fragment_entry = None;
        self
    }

    pub fn bind_group(mut self, layout: &'a wgpu::BindGroupLayout) -> Self {
        self.bind_groups.push(layout);
        self
    }

    pub fn vertex_buffer(mut self, layout: wgpu::VertexBufferLayout<'a>) -> Self {
        self.vertex_buffers.push(layout);
        self
    }

    pub fn color_target(mut self, target: wgpu::ColorTargetState) -> Self {
        self.targets.push(Some(target));
        self
    }

    pub fn primitive(mut self, state: wgpu::PrimitiveState) -> Self {
        self.primitive = state;
        self
    }

    pub fn depth_stencil(mut self, state: wgpu::DepthStencilState) -> Self {
        self.depth_stencil = Some(state);
        self
    }

    pub fn build(self) -> wgpu::RenderPipeline {
        let layout_label = format!("{}_layout", self.label);
        let pipeline_layout = self.device.create_pipeline_layout(&wgpu::PipelineLayoutDescriptor {
            label: Some(&layout_label),
            bind_group_layouts: &self.bind_groups,
            push_constant_ranges: &[],
        });

        let pipeline = self.device.create_render_pipeline(&wgpu::RenderPipelineDescriptor {
            label: Some(self.label),
            layout: Some(&pipeline_layout),
            vertex: wgpu::VertexState {
                module: self.shader,
                entry_point: Some(self.vertex_entry),
                buffers: &self.vertex_buffers,
            },
            fragment: self.fragment_entry.map(|entry| wgpu::FragmentState {
                module: self.shader,
                entry_point: Some(entry),
                targets: &self.targets,
            }),
            primitive: self.primitive,
            depth_stencil: self.depth_stencil,
            multisample: wgpu::MultisampleState::default(),
            multiview: None,
            cache: None,
        });

        // 自动注册到资源追踪器
        gpu_resource_tracker::track_pipeline(&pipeline);

        pipeline
    }
}
```

### 2.2 统一 Renderer Trait

```rust
// lumino-gfx/src/renderer.rs

/// 统一渲染器接口
/// 
/// 所有 gfx 子渲染器实现此 trait，由 RenderContext 统一调度。
pub trait Renderer {
    /// 初始化：创建 pipeline、buffer、bind group
    fn init(&mut self, device: &wgpu::Device, queue: &wgpu::Queue, format: wgpu::TextureFormat);

    /// 准备：根据编辑器状态更新 GPU 资源
    fn prepare(&mut self, device: &wgpu::Device, queue: &wgpu::Queue, view: &EditorView, document: &Document);

    /// 渲染：执行 render pass
    fn render<'a>(&'a self, render_pass: &mut wgpu::RenderPass<'a>);

    /// 窗口大小变化时调用
    fn resize(&mut self, device: &wgpu::Device, width: u32, height: u32);

    /// 释放 GPU 资源（自动从追踪器注销）
    fn cleanup(&mut self, device: &wgpu::Device);
}

/// 渲染上下文：管理所有子渲染器
pub struct RenderContext {
    renderers: Vec<Box<dyn Renderer>>,
    surface: wgpu::Surface,
    device: wgpu::Device,
    queue: wgpu::Queue,
}

impl RenderContext {
    pub fn render(&mut self, view: &EditorView, document: &Document) {
        // 1. 准备所有渲染器
        for renderer in &mut self.renderers {
            renderer.prepare(&self.device, &self.queue, view, document);
        }

        // 2. 获取 surface texture
        let frame = self.surface.get_current_texture().unwrap();
        let view = frame.texture.create_view(&wgpu::TextureViewDescriptor::default());

        // 3. 执行 render pass
        let mut encoder = self.device.create_command_encoder(&wgpu::CommandEncoderDescriptor::default());
        {
            let mut render_pass = encoder.begin_render_pass(&wgpu::RenderPassDescriptor {
                color_attachments: &[Some(wgpu::RenderPassColorAttachment {
                    view: &view,
                    resolve_target: None,
                    ops: wgpu::Operations {
                        load: wgpu::LoadOp::Clear(wgpu::Color::BLACK),
                        store: wgpu::StoreOp::Store,
                    },
                })],
                ..Default::default()
            });

            for renderer in &self.renderers {
                renderer.render(&mut render_pass);
            }
        }

        // 4. 提交
        self.queue.submit(std::iter::once(encoder.finish()));
        frame.present();
    }
}
```

### 2.3 GPU 资源自动追踪

```rust
// lumino-gfx/src/gpu_resource_tracker.rs

use std::sync::atomic::{AtomicU64, Ordering};

static GPU_MEMORY_BYTES: AtomicU64 = AtomicU64::new(0);

/// 自动追踪的 Buffer 包装器
pub struct TrackedBuffer {
    buffer: wgpu::Buffer,
    size: u64,
}

impl TrackedBuffer {
    pub fn new(device: &wgpu::Device, desc: &wgpu::BufferDescriptor) -> Self {
        let buffer = device.create_buffer(desc);
        let size = desc.size;
        GPU_MEMORY_BYTES.fetch_add(size, Ordering::Relaxed);
        lumino_memtrace::add_gpu_resource(size);

        Self { buffer, size }
    }

    pub fn inner(&self) -> &wgpu::Buffer { &self.buffer }
}

impl Drop for TrackedBuffer {
    fn drop(&mut self) {
        GPU_MEMORY_BYTES.fetch_sub(self.size, Ordering::Relaxed);
        lumino_memtrace::sub_gpu_resource(self.size);
    }
}

/// 自动追踪的 Texture 包装器
pub struct TrackedTexture {
    texture: wgpu::Texture,
    size: u64,
}

impl TrackedTexture {
    pub fn new(device: &wgpu::Device, desc: &wgpu::TextureDescriptor) -> Self {
        let texture = device.create_texture(desc);
        let size = texture_size_bytes(desc.format, desc.size);
        GPU_MEMORY_BYTES.fetch_add(size, Ordering::Relaxed);
        lumino_memtrace::add_gpu_resource(size);

        Self { texture, size }
    }

    pub fn inner(&self) -> &wgpu::Texture { &self.texture }
    pub fn create_view(&self, desc: &wgpu::TextureViewDescriptor) -> wgpu::TextureView {
        self.texture.create_view(desc)
    }
}

impl Drop for TrackedTexture {
    fn drop(&mut self) {
        GPU_MEMORY_BYTES.fetch_sub(self.size, Ordering::Relaxed);
        lumino_memtrace::sub_gpu_resource(self.size);
    }
}

/// 自动追踪的 Pipeline 包装器
pub struct TrackedPipeline {
    pipeline: wgpu::RenderPipeline,
    // pipeline 本身不占 GPU 显存，但追踪创建次数有助于调试
}

impl TrackedPipeline {
    pub fn new(pipeline: wgpu::RenderPipeline) -> Self {
        gpu_resource_tracker::track_pipeline(&pipeline);
        Self { pipeline }
    }

    pub fn inner(&self) -> &wgpu::RenderPipeline { &self.pipeline }
}
```

### 2.4 Shader 管理统一

```rust
// lumino-gfx/src/shader.rs

use std::collections::HashMap;

/// Shader 缓存：避免重复编译相同 shader
pub struct ShaderCache {
    device: wgpu::Device,
    cache: HashMap<String, wgpu::ShaderModule>,
}

impl ShaderCache {
    pub fn new(device: wgpu::Device) -> Self {
        Self { device, cache: HashMap::new() }
    }

    pub fn load(&mut self, name: &str, source: &str) -> &wgpu::ShaderModule {
        self.cache.entry(name.to_string()).or_insert_with(|| {
            self.device.create_shader_module(wgpu::ShaderModuleDescriptor {
                label: Some(name),
                source: wgpu::ShaderSource::Wgsl(source.into()),
            })
        })
    }

    pub fn load_embedded(&mut self, name: &str) -> &wgpu::ShaderModule {
        let source = match name {
            "note" => include_str!("shaders/note.wgsl"),
            "miditrail" => include_str!("shaders/miditrail.wgsl"),
            "keyboard" => include_str!("shaders/keyboard.wgsl"),
            "grid" => include_str!("shaders/grid.wgsl"),
            _ => panic!("Unknown shader: {}", name),
        };
        self.load(name, source)
    }
}
```

### 2.5 NoteRenderer 重构示例

```rust
// lumino-gfx/src/renderers/note.rs

use super::{Renderer, PipelineBuilder, TrackedBuffer, TrackedTexture};

pub struct NoteRenderer {
    pipeline: wgpu::RenderPipeline,
    vertex_buffer: TrackedBuffer,
    index_buffer: TrackedBuffer,
    instance_buffer: TrackedBuffer,
    uniform_buffer: TrackedBuffer,
    bind_group: wgpu::BindGroup,
    note_count: usize,
}

impl Renderer for NoteRenderer {
    fn init(&mut self, device: &wgpu::Device, _queue: &wgpu::Queue, format: wgpu::TextureFormat) {
        let shader = device.create_shader_module(wgpu::ShaderModuleDescriptor {
            label: Some("note_shader"),
            source: wgpu::ShaderSource::Wgsl(include_str!("../shaders/note.wgsl")),
        });

        let uniform_layout = device.create_bind_group_layout(&wgpu::BindGroupLayoutDescriptor {
            label: Some("note_uniform_layout"),
            entries: &[...],
        });

        self.pipeline = PipelineBuilder::new(device, "note_pipeline", &shader)
            .bind_group(&uniform_layout)
            .vertex_buffer(NoteVertex::layout())
            .color_target(wgpu::ColorTargetState {
                format,
                blend: Some(wgpu::BlendState::ALPHA_BLENDING),
                write_mask: wgpu::ColorWrites::ALL,
            })
            .build();

        // 创建 buffer（自动追踪）
        self.vertex_buffer = TrackedBuffer::new(device, &wgpu::BufferDescriptor {
            label: Some("note_vertices"),
            size: 1024 * 1024, // 1MB initial
            usage: wgpu::BufferUsages::VERTEX | wgpu::BufferUsages::COPY_DST,
            mapped_at_creation: false,
        });

        // ... 其他 buffer
    }

    fn prepare(&mut self, device: &wgpu::Device, queue: &wgpu::Queue, view: &EditorView, document: &Document) {
        let notes = document.current_track_notes();
        if notes.len() != self.note_count {
            // 重新分配 instance buffer（自动追踪旧 buffer 释放）
            self.instance_buffer = TrackedBuffer::new(device, &wgpu::BufferDescriptor {
                label: Some("note_instances"),
                size: (notes.len() * std::mem::size_of::<NoteInstance>()) as u64,
                usage: wgpu::BufferUsages::VERTEX | wgpu::BufferUsages::COPY_DST,
                mapped_at_creation: false,
            });
            self.note_count = notes.len();
        }

        // 上传实例数据
        let instances: Vec<NoteInstance> = notes.iter().map(|n| NoteInstance::from(n, view)).collect();
        queue.write_buffer(self.instance_buffer.inner(), 0, bytemuck::cast_slice(&instances));
    }

    fn render<'a>(&'a self, render_pass: &mut wgpu::RenderPass<'a>) {
        render_pass.set_pipeline(&self.pipeline);
        render_pass.set_bind_group(0, &self.bind_group, &[]);
        render_pass.set_vertex_buffer(0, self.vertex_buffer.inner().slice(..));
        render_pass.set_vertex_buffer(1, self.instance_buffer.inner().slice(..));
        render_pass.set_index_buffer(self.index_buffer.inner().slice(..), wgpu::IndexFormat::Uint16);
        render_pass.draw_indexed(0..6, 0, 0..self.note_count as u32);
    }

    fn resize(&mut self, _device: &wgpu::Device, _width: u32, _height: u32) {
        // NoteRenderer 不需要处理 resize
    }

    fn cleanup(&mut self, _device: &wgpu::Device) {
        // TrackedBuffer 的 Drop 会自动处理
    }
}
```

## 三、重构收益

### 3.1 代码量减少

| 项目 | 当前 | 重构后 | 减少 |
|------|------|--------|------|
| Pipeline 创建代码 | 27 处 × 25 行 = 675 行 | 6 处 × 10 行 = 60 行 | -91% |
| GPU 资源追踪调用 | 50+ 处手动调用 | 0（自动） | -100% |
| Renderer 初始化 | 6 个文件各自实现 | 1 个 trait + 6 个 impl | 结构清晰 |
| Shader 加载 | 6 处重复 | 1 个缓存 | -83% |

### 3.2 可靠性提升

- **消除手动追踪遗漏**：`TrackedBuffer`/`TrackedTexture` 的 `Drop` 自动注销
- **统一错误处理**：`Renderer::init` 返回 `Result`，强制处理失败
- **资源生命周期明确**：RAII 模式，无手动 `sub_buffer` 调用

### 3.3 可扩展性提升

新增 renderer 只需：
1. 实现 `Renderer` trait（4 个方法）
2. 使用 `PipelineBuilder` 创建 pipeline（1 行）
3. 使用 `TrackedBuffer`/`TrackedTexture` 管理资源（自动）
