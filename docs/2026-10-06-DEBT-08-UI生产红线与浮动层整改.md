## 修复方案

1. 逐处替换：`let-else return` / `poisoned.into_inner()` / `filter_map` / 返回 `Result`；
2. `rfd::FileDialog` 挪后台线程 + 事件回传；
3. `OverlayKind` 优先级函数 + 互斥断言；补齐 color picker 互斥与死事件清理；
4. 注释与常量收口。
