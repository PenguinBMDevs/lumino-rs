## 1. 交付内容

关于页顶部新增 Lumino logo（复用 `Icon::LogoInApp`，未新建面板/窗口），并实现其彩蛋交互：

- 单击 logo → **原地晃动一次**（0.30s、衰减收正弦、±7px）；
- 连点累计满 **15** 次触发彩蛋序列；相邻点击间隔超过 **2s** 则计数清零重新累计（惰性判定，无定时器）；
- 序列：**快速转动（2 圈 / 0.5s）→ 脱离原位（0.22s ease-out）→ 飞向窗口中轴 Y 以上随机位置 → 匀加速砸向窗口底部（0.55s）→ 打入位停顿（0.08s，音效挂载点）→ 渐隐消失（0.35s）**；
- 消失状态**仅进程内保持**：重开设置面板/关于页不再出现，重启 APP 恢复，不写任何配置。

## 3. 关键设计决策

1. **消失标志放进程级 static，而非面板状态**：设置面板是独立窗口，`close_dialog` 会 drop `DialogWindow`，每次打开都 `Host::new_settings_dialog` → 全新 `RootState`（`dialog/src/manager/lifecycle.rs:157`、`ui/src/host/builder.rs:181`）。面板内任何字段都会被重置，承载不了"重开不再出现"。静态标志同时天然满足"不持久化、重启恢复"。
2. **几何全部在像素域解算**：`window::Window` 无尺寸字段、视图层拿不到 viewport，故由 Host 每帧 `set_viewport()` 注入、点击时 `set_click_point()` 注入光标；状态机负责钳制（落点仅取中轴 Y 以上、落地钳在窗口底部内），视图只做"位置 → 布局"无损换算。
3. **悬浮层挂 `view_dialog`（整窗）而非设置内容区**：使悬浮层坐标系与 Host 视口坐标系逐像素一致，消除自有标题栏 30px 的坐标错位；logo 可越过标题栏但仍严格限制在窗口可见区内。
4. **飞行层的点击穿透**：该层只由容器/占位器/Svg 组成，**不套 `mouse_area`**，iced 对未捕获事件的层向下穿透 → 底层设置内容照常可点（对比 `settings_dialog.rs` 的 BPM 遮罩是**故意**用 `mouse_area` 捕获点击的）。
5. **动画状态只在 `update` 推进**：`Root::view(&self)` 只读，故推进点在 `handle_animation_tick`；视图纯函数化，便于测试。
6. **不引入 `rand`**：xorshift64（种子取系统时间）完成一次随机落点采样，避免为单点需求加依赖。

## 4. 落地陷阱（研究阶段未预判）

- **F4｜`SettingsPanel::update` 是穷尽匹配、无 catch-all**：新增 `Event` 变体必须在 `ui-settings/src/panel.rs` 同步补 arm，否则直接编译失败（已补，含说明注释）。
- iced `Svg` 以**旋转后包围盒**参与 `ContentFit::Contain` 缩放：不做补偿时非正方形 logo 在转动中会周期性缩到约 77%。已用 `spin_fit_scale()`（AABB 长边比）补偿，使绘制尺寸恒定；控件放进固定方盒居中，吸收布局盒呼吸。
- 对话框的 `ui_dirty` 只在"消息产生状态变更"或 iced 返回 `State::Updated` 时被置位（`host/event/window/events.rs::update_ui_state`）；事件队列清空后 `render_iced_ui` 会走"仅 present 缓存帧"的早退路径（`host/render/ui.rs:30-39`），**只喂 tick 不置脏 = 动画冻结**。已在 `frame.rs` 动画期显式置脏（先例：同文件播放分支）。
