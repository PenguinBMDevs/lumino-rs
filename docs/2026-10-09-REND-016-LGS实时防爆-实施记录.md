## 一、三步改动

### 步骤 1：LGS 全局复音上限透传（止血）

- `UiConfig.lgs_global_voice_limit`（None = 自动 = **16384**，`LGS_AUTO_MAX_VOICES`）；
- `LgsOptions.max_voices` → `SynthConfig.max_voices`（复用既有 fade-steal 池治理，REND-015）；
- LGS 设置页「全局最大复音数」滑块（0=自动，夹紧 64..65536）；`lgs_changed` 触发重初始化；
- 行为变化说明：GPU 旧默认 = `0`（无限/黑 MIDI 模式）→ 现在默认 16384，这是本卡的有意变更
  （无限模式正是"30k 声部全进一次 dispatch"的直接成因；仍可配置回大值）；
- 顺带：`api/lgs.rs` 测试外移 `api/lgs/tests.rs`（424 → <400 行，移出白名单，42 → 41）。

### 步骤 2：事件积压治理（事件闸）

- `StampedEvent`：事件入队盖墙钟时间戳（发送端），渲染线程按年龄治理；
- 有界 drain：每块 ≤ 4096 条；最老事件年龄 > 4×deadline 时放宽到 65536（尽快冲积压）；
- deadline = max(3×块时长, 50ms)；**只丢弃过期 NoteOn**（NoteOff / 状态类事件永不丢——
  防挂音 / 上下文错乱）；
- `dropped_note_ons` 进入 `PlaybackStatsReader`；限频 `[EVENT-DROP]` stderr 打点。

### 步骤 3：负载治理器 + 准入预算（反馈闸；S3 并入 L4）

- Governor 四级（Normal / High / Overload / Emergency）：EMA α=0.2；升级阈值
  0.9 / 1.2 / 1.5（持续 20 块）；恢复 <0.7（持续 100 块）逐级回落；
  Emergency 退出后冷却 235 块（≈5s，防"丢弃→负载降→退出→再进入"密度泵动）；
- 「时间已落后」证据（事件闸紧急放宽）可越过持续块数要求**直入 Emergency**（冷却期除外）；
- Overload / Emergency 对**新鲜 NoteOn** 施加单块准入预算 4096 / 2048（保节奏优先；
  NoteOff / 状态类事件不受限）；
- `governor_level` 观测 + 级别切换 `[GOVERNOR]` 打点。
