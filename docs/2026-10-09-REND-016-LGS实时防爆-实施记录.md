## 一、三步改动

### 步骤 1：LGS 全局复音上限透传（止血）

- `UiConfig.lgs_global_voice_limit`（None = 自动 = **16384**，`LGS_AUTO_MAX_VOICES`）；
- `LgsOptions.max_voices` → `SynthConfig.max_voices`（复用既有 fade-steal 池治理，REND-015）；
- LGS 设置页「全局最大复音数」滑块（0=自动，夹紧 64..65536）；`lgs_changed` 触发重初始化；
- 行为变化说明：GPU 旧默认 = `0`（无限/黑 MIDI 模式）→ 现在默认 16384，这是本卡的有意变更
  （无限模式正是"30k 声部全进一次 dispatch"的直接成因；仍可配置回大值）；
- 顺带：`api/lgs.rs` 测试外移 `api/lgs/tests.rs`（424 → <400 行，移出白名单，42 → 41）。

### 步骤 2：事件积压治理（事件闸）

- `StampedEvent`：事件入队盖墙钟时间戳（发送端），渲染线程按年龄治理；
- 有界 drain：每块 ≤ 4096 条；最老事件年龄 > 4×deadline 时放宽到 65536（尽快冲积压）；
- deadline = max(3×块时长, 50ms)；**只丢弃过期 NoteOn**（NoteOff / 状态类事件永不丢——
  防挂音 / 上下文错乱）；
- `dropped_note_ons` 进入 `PlaybackStatsReader`；限频 `[EVENT-DROP]` stderr 打点。

### 步骤 3：负载治理器 + 准入预算（反馈闸；S3 并入 L4）

- Governor 四级（Normal / High / Overload / Emergency）：EMA α=0.2；升级阈值
  0.9 / 1.2 / 1.5（持续 20 块）；恢复 <0.7（持续 100 块）逐级回落；
  Emergency 退出后冷却 235 块（≈5s，防"丢弃→负载降→退出→再进入"密度泵动）；
- 「时间已落后」证据（事件闸紧急放宽）可越过持续块数要求**直入 Emergency**（冷却期除外）；
- Overload / Emergency 对**新鲜 NoteOn** 施加单块准入预算 4096 / 2048（保节奏优先；
  NoteOff / 状态类事件不受限）；
- `governor_level` 观测 + 级别切换 `[GOVERNOR]` 打点。

## 五、现场复测驱动的补强（2026-10-10）

真机复测（Bad Apple 8.49M + LGS，日志实测）后追加四项，收口同一条因果链：

1. **观测进文件日志**（`e2a23778`）：`[UNDERRUN]` / `[EVENT-DROP]` / `[GOVERNOR]` /
   `[render] block error` / playback error 全部接入 tracing（GUI release 无控制台，
   eprintln 会丢失）；`[GOVERNOR]` 增补 load EMA / voices / 运行时声部上限；
2. **紧急冲洗**（`e12308b2`）：积压深（最老事件年龄 >4×deadline）时**一次调用**扫完
   过期区（上限 2M 条），消除"积压追平期间数秒级静音"；
3. **L4 动态收缩复音上限**（`a47eb202`）：新增 `GpuSynth::set_runtime_voice_limit`；
   Overload → 8192 / Emergency → 4096，恢复期逐级回升——过载时块渲染成本 ∝ 声部数
   下降，把渲染耗时拉回实时预算；
4. **发送端 NoteOn 准入限速**（`0ff1cf27`，GPU 软 NPS 闸）：Normal/High 不限；
   Overload ≈32k 音符/s；Emergency ≈8k 音符/s；仅限 vel>0 的 NoteOn
   （NoteOff / 状态类 / vel=0 全放行）。现场日志实测洪峰 **~1.8M 事件/s**，
   渲染端冲洗治不了入口速率；限速把洪峰变为细流。

复测日志关键证据（2026-10-10 01:53 会话）：`[EVENT-FLUSH]` 单次扫描
77,775 → 1,123,364 条、丢弃 29,095 → 462,727；Governor L3(4096) → L2(8192) →
L1(65536) → L0；**UNDERRUN = 0**（静音来自"无新鲜事件可发声"，不是音频队列欠载）。

测试增量：gpu-synth 68 → 77（drain/governor/冲洗/上限口径/NPS 闸）+ 升采样低频
透明性回归 1 项；midi-io / runner / ui-settings 回归全绿。

### 二次复测补强（同日）

5. **令牌桶 + 防爆闸开关**（`3c04b347`）：刚性最小间隔改为与 CPU `EmergencyGate`
   对齐的**令牌桶**（突发 50ms 成组放行、µs 粒度补充）——和弦/重音不再被拆散；
   被拒 NoteOn 的 NoteOff **配对抵消**（防挂音、减少事件量）；新增「**LGS 防爆闸**」
   设置开关（默认开，i18n 中英），供 A/B 对照「连续但变薄」（开）与「周期性静音」
   （关）两种降级体感。gpu-synth 测试 77 → 78。

6. **释放改看丢弃压力**（`35fe2912`，现场反馈"爆点过后先静一段才恢复"）：
   Governor 释放条件由「负载 EMA <0.7 持续 100 块（≈2s+，要等引擎静下来）」
   改为「**丢弃压力消失**持续 20 块（≈0.4s）」；压力 = 发送端闸丢弃 + 渲染端
   过期/预算丢弃 + 紧急冲洗——压力在则保持限速（防风暴未过就放行），风暴一停
   即逐级放行。同时紧急冲洗/治理触发提前（4×→2×deadline ≈100ms），减少闸
   生效前的静音窗口。gpu-synth 测试 78 → 79。

7. **过载重同步**（`d0ece9de` 初版 + 出口口径修订）：引擎一旦落后于时间线，内容
   无法自对齐（长衰减声部残留 + 音频队列里的旧渲染缓冲 + 当前事件叠在一起）。
   修订后的口径：
   - **入口**（进入 Emergency）：**全清**——所有在响声部（含释放尾巴）5ms 淡出 +
     递增音频 flush 纪元（回调丢弃已渲染旧缓冲）；
   - **出口**（离开 Emergency）：只清**风暴期出生**的余波（`spawn_frame <` 干净
     窗口起点，含其释放尾巴），**不动新段落声部、不动音频缓冲**——初版在出口也做
     全清 + 缓冲丢弃，把新段落刚渲染的打击乐/砸琴整段丢掉（现场直观证据）。
   `[RESYNC]` 打点区分「入口全清 / 出口清余波」。gpu-synth 79 → 81。
